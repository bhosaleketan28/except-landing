# Except. — Mastech landing page concept

The landing page for the "Except." campaign: "Your AI knows the rule. You know the exception."
One page with a Light / Dark switch in the top right corner.

Campaign concept by Ketan Bhosale. All scenarios on the page are illustrative.

## What is in this folder

| File | What it is |
|---|---|
| `index.html` | The whole page: layout, colours and behaviour in one file |
| `img/` | Photographs and the Mastech logo |
| `fonts/` | Space Grotesk and Inter (open licences) |
| `vercel.json` | Small hosting settings for Vercel |

There is no build step. The folder is a plain static website, and `index.html` also opens by double-clicking.

## Put it online with GitHub and Vercel

1. On github.com, create a new repository, for example `except-landing`. Keep it empty.
2. On the repository page choose **Add file → Upload files**, drag in everything inside this folder (not the folder itself), and commit.
3. On vercel.com choose **Add New → Project**, pick the repository, and when asked for a framework choose **Other**. Leave every other setting as it is and press **Deploy**.
4. Vercel gives you a link. In **Settings → Domains** you can rename it, for example `except-landing.vercel.app`.

Every later change you upload to GitHub goes live automatically.

## What a visitor can do

- Switch between Light and Dark at the top right. The choice is remembered on their device.
- Highlight the reserved line on the record (or press the link in the AI agent's reply) and watch the answer change from 240 to 60.
- Point at the five rows in "What Mastech connects" to change the picture.
- Pick a rule under "It is not only stock" to see its record.
- Answer the three questions and copy the brief. Nothing is sent anywhere.
